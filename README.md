# 서울사이버대학교 포털서비스(학생)

학생 포털 화면에 이벤트와 탭, 반응형을 적용했습니다.

## 구현한 이벤트

- **click**: 탭 버튼 3개(학습활동, 학점 이수 현황, 학사공지), 상단 메뉴, 상담 예약 버튼
- **input**: 연락처 입력 시 하이픈 자동 입력 및 형식 검사
- **change**: 상담 유형 선택 시 안내 문구 변경

## 화면 변화

- 탭 클릭: 선택한 탭만 색이 바뀌고 해당 내용만 표시
- 연락처 입력: 형식이 맞으면 초록색 + "올바른 연락처입니다." + 예약 버튼 활성화, 틀리면 빨간색 + 안내 문구 + 버튼 비활성화
- 상담 유형 변경: 안내 문구(상담 유형, 운영 시간) 변경
- 상담 예약 클릭: 버튼이 "예약 완료"(초록색)로 바뀌고 입력창 잠금

## 중간고사

- 상담 예약
  - 확인할 조건: 같은 유형으로 예약중인 상담이 없는가
  - 성공 반응: 내역에 추가, 초록 안내, 연락처 입력 초기화
  - 다른 분기: 같은 유형이 있으면 빨간 안내 (입력값은 유지)
  - 다음 행동: 다른 유형을 고르거나 기존 예약을 취소한 뒤 다시 예약
- 예약 취소
  - 확인할 조건: 예약중인 항목
  - 성공 반응: "취소됨"으로 바뀌고 회색·취소선 표시
  - 다음 행동: 다시 예약
- 다시 예약
  - 확인할 조건: 취소된 항목
  - 성공 반응: 유형과 연락처가 폼에 채워짐
  - 다음 행동: 상담 예약
- 내역 없음
  - 확인할 조건: 예약한 내역이 하나도 없음
  - 성공 반응: "아직 예약 내역이 없습니다" 안내
  - 다음 행동: 상담 예약하러 가기(폼으로 이동)
