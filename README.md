# 서울사이버대학교 포털서비스(학생)

학생 포털 화면에 이벤트와 탭, 반응형을 적용했습니다.

## 구현한 이벤트

- **click**: 탭 버튼 3개(학습활동, 학점 이수 현황, 학사공지), 상단 메뉴, 상담 예약 버튼
- **input**: 연락처 입력 시 하이픈 자동 입력 및 형식 검사
- **change**: 상담 유형 선택 시 안내 문구 변경

## 화면 변화

- 탭 클릭: 선택한 탭만 색이 바뀌고 해당 내용만 표시
- 연락처 입력: 형식이 맞으면 초록색 + "올바른 연락처입니다." + 예약 버튼 활성화, 틀리면 빨간색 + 안내 문구 + 버튼 비활성화
- 상담 유형 변경: 안내 문구(상담 유형, 운영 시간) 변경
- 상담 예약 클릭: 버튼이 "예약 완료"(초록색)로 바뀌고 입력창 잠금
